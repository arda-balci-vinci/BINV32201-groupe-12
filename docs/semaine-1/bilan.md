# Bilan 

### 1. Qu'est-ce que Copilot vous a aidés à faire ?
Copilot nous a aidés à générer la structure du filtre dans le composant React, à propager le query parameter `period` à travers les couches de l'application (hook, service API, contrôleur backend et repository SQL), ainsi qu'à rédiger le boilerplate des tests automatisés Vitest.

### 2. Qu'avez-vous vérifié ou corrigé vous-mêmes ?
Nous avons vérifié que la clause SQL respectait bien la combinaison entre les règles de visibilité par rôle et le filtre optionnel, ajusté les typages TypeScript, et vérifié que la documentation `backend/API.md` restait fidèle au contrat d'interface. Nous avons également relu et corrigé `.github/copilot-instructions.md`.

### 3. Quelle difficulté ou limite avez-vous rencontrée ?
Nous trouvons que pour cette séance, il n'y a pas eu de réelle difficulté ou limite.
